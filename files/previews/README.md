# Homepage video previews

These silent previews use public videos from the author's project pages. All
source frames are preserved: the videos are scaled and padded to 640 × 360,
never cropped. Encoding: H.264, 20 fps, with MP4 metadata at the start for playback.

## GameScaling

Project: https://gamescaling.github.io/

- Minecraft, GameScaling-27B-S3, 0.8–6.8 seconds:
  https://gamescaling.github.io/videos/mixture/mcu/mine_birch_log/27b_s3.mp4
- Doom, GameScaling-27B-S3, 27–35 seconds:
  https://gamescaling.github.io/videos/mixture/vizdoom/defend_the_line/27b_s3.mp4

The 14-second preview plays these two examples consecutively. The homepage's
demo link opens the complete project introduction video.

## Video-Arena

Project: https://videoarena-bench.github.io/

Source: https://videoarena-bench.github.io/videos/promo.mp4

The 17.2-second preview uses the continuous gameplay sequence at 38.3–55.5s:
Go, chess, Doudizhu, Counter-Strike 2, StarCraft II, and football. The original
event-perception, state-interpretation, and state-tracking captions remain visible. The homepage's demo link opens the complete 84-second video.

The corresponding poster images in `images/previews/` are extracted from the
new previews at 1.8 seconds. Game footage remains attributed to its original
publishers, as described on the project pages.
