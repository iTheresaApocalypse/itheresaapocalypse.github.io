# Homepage video previews

These silent previews use public videos from the author's project pages. All
the full source frame is preserved with scaling and padding, never cropping.
Encoding: H.264, 20 fps, with MP4 metadata at the start for playback.

  https://gamescaling.github.io/videos/mixture/vizdoom/defend_the_line/27b_s3.mp4

  https://gamescaling.github.io/videos/mixture/oga/monster_shoot/27b_s3.mp4
- Pac-Man, GameScaling-27B-S3, 1–15 seconds:
  https://gamescaling.github.io/videos/mixture/gw/pacman/27b_s3.mp4

`gamescaling-grid.mp4` is a 14-second, 960 × 608 preview showing all four games
simultaneously in a 2 × 2 grid. Each panel has its game name above the complete
gameplay frame, including the project's model/action annotations. The matching
poster is `images/previews/gamescaling-grid.jpg`, extracted at 2 seconds.
The homepage's demo link opens the complete project introduction video.
The original sequential `gamescaling.mp4` remains available for old links.

## Video-Arena

Project: https://videoarena-bench.github.io/

Source: https://videoarena-bench.github.io/videos/promo.mp4

The 17.2-second, 640 × 360 preview uses the continuous gameplay sequence at 38.3–55.5s:
Go, chess, Doudizhu, Counter-Strike 2, StarCraft II, and football. The original
event-perception, state-interpretation, and state-tracking captions remain visible. The homepage's demo link opens the complete 84-second video.

The Video-Arena poster in `images/previews/` is extracted at 1.8 seconds.
Game footage remains attributed to its original
publishers, as described on the project pages.
